# Welcome

Welcome to **Example Company**. This handbook explains how our team works, which tools we use and what we expect from each other.

This is a template with fictional content. Replace the company name, the logo and the example rules with your own.
:::

## Purpose

1. Give new colleagues a fast and calm start.
2. Describe our working agreements in one place.
3. Reduce questions that are answered the same way every time.
4. Make our decisions visible.

## Values

| Value | What it means in practice |
|-------|---------------------------|
| Clarity | We write things down and say what we mean. |
| Quality | We finish what we start and test before we ship. |
| Respect | We assume good intent and give honest feedback. |
| Curiosity | We learn from mistakes and share what we find out. |
| Ownership | We take responsibility for results, not only for tasks. |

## Organisation

| Team | Responsibility |
|------|----------------|
| Product | Requirements, priorities, customer contact |
| Engineering | Design, implementation, testing |
| Operations | Infrastructure, deployment, monitoring |
| Administration | Contracts, finance, personnel |
